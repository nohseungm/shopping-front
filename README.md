# CLOTHING SHOP

HTML / CSS / JavaScript(Vanilla)로 구현한 온라인 의류 쇼핑몰 프론트엔드 프로젝트입니다.
상품 조회 → 찜하기 → 장바구니 → 결제 → 전자 영수증 출력까지 이어지는 쇼핑몰 흐름을 정적 페이지만으로 구현했습니다.

## 데모

브라우저에서 `index.html`을 열거나, 아래 "로컬 실행" 방법으로 로컬 서버에서 실행해 확인할 수 있습니다.

## 주요 기능

- **상품 목록**: 카드 형식으로 상품을 출력하고, 카테고리(전체/티셔츠/청바지/아우터/슬랙스) 필터 버튼 제공
- **찜하기**: 하트 아이콘 클릭으로 찜 추가/삭제, `index.html#liked`에서 찜한 상품만 모아보기
- **장바구니**: 수량 증감(➕/➖), 개별 삭제, 총 금액 자동 계산
- **결제**: 이름/주소/전화번호/결제수단 입력 후 결제 처리(필수 입력 검증 포함)
- **전자 영수증**: 결제 완료 시 주문번호(임의 생성)와 결제 일시가 포함된 영수증 표시

## 기술 스택

- HTML5 / CSS3
- JavaScript (ES6+, 프레임워크 없이 Vanilla JS)
- `localStorage`를 이용한 클라이언트 사이드 상태 저장 (장바구니, 찜 목록)

별도의 서버/백엔드나 빌드 과정 없이 동작하는 정적 사이트입니다.

## 프로젝트 구조

```
.
├── index.html          # 홈 (상품 목록 / 찜한 상품 보기 #liked)
├── cart.html            # 장바구니
├── pay.html              # 결제 / 전자 영수증
├── css/
│   ├── style.css        # 공통 레이아웃 및 상품/장바구니 스타일
│   ├── pay.css           # 결제 페이지 스타일
│   └── logo.css          # 로고 컴포넌트 스타일
├── js/
│   ├── script.js         # 홈: 상품 렌더링, 카테고리 필터, 찜하기
│   ├── cart.js            # 장바구니: 렌더링, 수량 변경, 삭제
│   └── pay.js              # 결제: 주문 요약, 영수증 생성, 결제 처리
└── img/                   # 로고 및 상품 이미지
```

## 로컬 실행

빌드 없이 정적 파일을 서빙하기만 하면 됩니다.

```bash
# 프로젝트 루트에서
python -m http.server 8000
# 브라우저에서 http://localhost:8000/index.html 접속
```

또는 VS Code의 Live Server 확장 등으로 `index.html`을 열어도 됩니다.
(`file://`로 직접 열어도 대부분 동작하지만, 로컬 서버 사용을 권장합니다.)

## 동작 확인

주요 플로우(카테고리 필터 → 찜하기 → 장바구니 담기/수량 변경/삭제 → 결제 → 영수증 생성 → 장바구니 초기화)를
Playwright로 자동화 테스트하여 콘솔 에러 없이 정상 동작함을 확인했습니다.

## 데이터 저장 및 보안 관련 안내

- 이 프로젝트는 **순수 클라이언트 사이드 데모**로, 별도의 서버나 데이터베이스가 없습니다.
- 장바구니(`cart`)와 찜 목록(`likes`)은 브라우저의 `localStorage`에만 저장되며, 외부로 전송되지 않습니다.
- 결제 폼에 입력한 이름/주소/전화번호는 어디에도 저장·전송되지 않고, 결제 완료 시 화면에서만 사용되고 사라집니다(실제 결제는 이루어지지 않는 학습용 시뮬레이션입니다).
- 코드 내 API 키, 비밀번호, 토큰 등 민감 정보는 포함되어 있지 않습니다.
- 고객센터 전화번호/이메일은 예시용 가상의 정보입니다.

## 알려진 제한 사항

- 실제 결제 연동(PG사) 없이 결제 완료를 시뮬레이션합니다.
- 상품 데이터는 `js/script.js` 내 정적 배열로 관리되며, 별도 관리자 페이지는 없습니다.
- `localStorage` 기반이므로 브라우저/기기 간 장바구니·찜 목록 동기화는 되지 않습니다.
